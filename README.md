# 🐍 Curso de Python - Curso em Vídeo

Repositório dedicado aos exercícios e desafios propostos pelo professor Gustavo Guanabara no Curso em Vídeo. O objetivo aqui é praticar lógica de programação, sintaxe e estruturas de dados.

## 📂 Sobre este Módulo

Este repositório contém as resoluções dos exercícios do **Mundo 3**, onde o foco é o tratamento de dados complexos e a organização do código em funções. É aqui que os programas começam a ter cara de "software":
* **Estruturas Compostas:** Manipulação de Tuplas, Listas e Dicionários.
* **Funções (def):** Criação de rotinas personalizadas e reutilizáveis.
* **Modularização:** Organização do código em múltiplos arquivos e pacotes.
* **Tratamento de Erros:** Uso de `try`, `except` e `finally` para criar programas resilientes.

## 🚀 Como executar

Como são scripts individuais, cada arquivo .py pode ser executado diretamente pelo terminal:

```
python pasta_do_exercicio/nome_do_arquivo.py
```

## 🛠️ Tecnologias

Linguagem: Python 3.x
Ambiente: PyCharm
Bibliotecas: `random`, `time`, `datetime`, `rich`, `os`
Versionamento: Git & GitHub
